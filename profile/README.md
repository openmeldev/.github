# Mel: the agentic terminal

Mel is a terminal where a team of AI agents plans, builds, tests and reviews your work,
and asks before the edits and commands you haven't allowed.

- macOS, Windows, Linux and VS Code
- Claude, GPT, Gemini, DeepSeek, Qwen, Kimi and GLM in one app
- Free with your own AI key; Pro, Max and Business include hosted credits
- Mel Business: one credit pool, one invoice, a spending limit per person
